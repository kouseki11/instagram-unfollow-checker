Panduan Download Data JSON Instagram

Ikuti langkah mudah ini dari aplikasi Instagram HP / Browser

PENTING: Saat meminta data di Instagram, pastikan Anda memilih format JSON (bukan HTML) agar file dapat dibaca oleh sistem.

  1. Buka aplikasi Instagram $\rightarrow$ masuk ke profil Anda $\rightarrow$ ketuk Menu (Ikon 3 Garis) di pojok kanan atas.
  2. Pilih Pusat Akun (Accounts Center).
  3. Pilih Informasi dan izin Anda (Your information and permissions).
  4. Klik Unduh informasi Anda (Download your information) $\rightarrow$ pilih Unduh atau transfer informasi.
  5. Pilih akun Instagram Anda $\rightarrow$ ketuk Sebagian informasi (Some of your information).
  6. Centang kategori Pengikut dan Mengikuti (Followers and following) $\rightarrow$ klik Berikutnya.
  7. Pilih Unduh ke perangkat (Download to device).
  8. Atur Konfigurasi:
    • Rentang tanggal: Sepanjang waktu (All time)
    • Format: JSON
  9. Klik Buat file. Tunggu notifikasi/email dari Instagram, lalu unduh dan ekstrak file ZIP-nya.
